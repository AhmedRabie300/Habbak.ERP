# قرارات استراتيجية — بعد مراجعة الموديول 1

## 1. ETA (الفاتورة الإلكترونية)

**القرار**: Optional — إعداد لكل شركة.

**التفاصيل**:
- الشركة تقدر تختار: ETA مفعّل / غير مفعّل.
- لو مفعّل → التكامل شغال.
- لو غير مفعّل → الحقول تختفي، والـ Checklist item يبقى `IsSatisfied = false` (أو يتشال).
- **الـ ETA مش هيتم بناؤه دلوقتي** — هيبقى في Roadmap لاحق.

**الـ Gap الحالي**: 
- بند "إرسال ETA" في Checklist الإقفال مُجبَر على `true`.
- **الإصلاح العاجل**: يبقى `false` افتراضيًا + يتفعل بس لما ETA يتبنى.
