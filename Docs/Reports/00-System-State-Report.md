## 3. أخطر 3 اكتشافات في الاختبار

### 🔴 البيع مكانش بيخصم أي مخزون
بيعة لاتيه أتمّت الدفع وأنشأت فاتورة بـ50.40 ج.م و**مخصمتش ولا وحدة**. السبب سطرين:
`if (!item.IsStocked) continue;` + **غياب كامل لأي منطق وصفات** في طبقة POS.

المنتجات التامة كلها `IsStocked = false` (بتتحضّر عند الطلب)، فالشرط ده كان بيبلع كل بيعة بصمت.

### 🔴 مكانش فيه محرك تكلفة من الأساس
- **363 صنف من 366** بدون تكلفة معيارية
- `CostMethod` مضبوطة `WeightedAverage` على **364 صنف** — **بدون أي كود بينفّذها**
- `StockBalance` **مفيهاش عمود قيمة** أصلًا

النتيجة: تقييم المخزون = صفر · COGS = صفر · قيمة الهالك = صفر.

### ⚠️ تصحيح فرضية متكررة
`IPostingService` **موجود ومبني** ومستخدم في الحسابات. اللي ناقص إنه **مش موصَّل** بمستندات
المشتريات/المخزون/POS. شرط "بدون قيود" كان بيتحقق تلقائيًا — بس لسبب مختلف عن المتوقع.

## 4. الحالة الحالية

### شغّال ومختبَر
- الدورة المستندية الخمسة كاملة، بتحرّك مخزون فعلي
- **محرك تكلفة** بالمتوسط المرجّح **لكل مخزن**، بيحفظ التكلفة عبر التحويلات
- **استهلاك وصفات لحظي** عند البيع (مقفول افتراضيًا — لازم تفعيل صريح)
- **تجميد تكلفة البيع** على سطر الفاتورة — جاهز لمحرك الترحيل
- حماية من تكرار الترحيل عبر `Idempotency-Key`

### قيمة المخزون الحقيقية دلوقتي
بعد إصلاح البيانات القديمة: **243,565.95 ج.م** بدل **صفر**.

### مش مبني
| البند | الملاحظة |
|---|---|
| **محرك القوالب المحاسبي** | موديول كامل: ~6 كيانات + Evaluator + Resolvers + 13 قالب + شاشتين |
| محرك المزامنة Offline | آخر مرحلة في POS، مؤجّلة بالاتفاق |
| موديول الموارد البشرية | **مفيش كيان `User` في النظام كله** — كل `UserId` مجرد `long` بدون FK |
| نظام الصلاحيات | `usePermission` مجرد stub بيرجّع true دايمًا |
| تكامل ETA الحقيقي | شكل البيانات والحالات بس، مفيش إرسال |

## 5. تحذيرات تشغيلية

| # | التحذير |
|---|---|
| 1 | **استهلاك الوصفات مقفول افتراضيًا** (`Stocked`). لازم صف `ProductionSalesModeSetting` بنطاق `Company` أو `Item` عشان يشتغل — قرار إداري مش افتراضي صامت، لأنه ممكن يبدأ **يرفض مبيعات** لو المكوّنات ناقصة (قاعدة 18). |
| 2 | **`Item.StandardCost` مش مصدر التكلفة** — المصدر هو `StockBalance.AverageCost` لكل مخزن. `StandardCost` تقديرية للمقارنة بس. |
| 3 | **مخزن نقطة البيع** لازم يكون مضبوط صح — `POS-01` كان بيشاور على المخزن **الرئيسي** مش مخزن الفرع، يعني البيع كان هيخصم من مخزن الشركة. |
| 4 | أسعار الدليفري في قائمة الأسعار **مفترضة** = تيك أواي. |
| 5 | وصفات **قسم القهوة (22 صنف)** مستنتجة بالكامل — تراجَع قبل الاعتماد على أرقام COGS منها. |
