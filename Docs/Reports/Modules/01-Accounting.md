## 2. الدورات المستندية

### 2.1 القيد اليومي
```
مسودة (Draft) ──── PostJournalEntry ────► مرحّل (Posted)
                                              │
                                     ReverseJournalEntry
                                              ▼
                                        معكوس (Reversed)
                    ↘ مرفوض (Rejected)
```
- **العكس بينشئ قيد جديد مقلوب** بحالة `Draft` — مش بيعدّل الأصلي، ومحتاج ترحيل صريح.
- القيود الآلية (`IsAutoGenerated`) بتتولد **`Posted` مباشرة** بدون `Draft` إطلاقًا.

### 2.2 السند (قبض/صرف)
```
مسودة ──── PostVoucher ───► مرحّل ──── ReverseVoucher ───► (قيد عكسي)
      ↘ CancelVoucher ──► ملغي        ↘ مرفوض
```
**الترحيل بيعمل حاجتين**: ينشئ القيد المحاسبي، **وبيكتب على رصيد الطرف** (مورد أو عميل).

> ⚠️ **حارس مهم** اتضاف بعد باج في QA المشتريات: عملة السند **لازم** تطابق عملة الشركة الأساسية،
> لأن `SalesInvoice` مالهاش حقل عملة أصلًا.

### 2.3 التحويل بين الخزائن
```
مسودة ──── PostTreasuryTransfer ───► مرحّل
```
دورة بسيطة بحالتين بس — مفيش إلغاء بعد الترحيل.

### 2.4 العهدة النقدية
```
مفتوحة (Open) ──► مسوّاة جزئيًا (PartiallySettled) ──► مقفولة (Closed)
                                                    ↘ ملغاة (Cancelled)
```
كل `CustodySettlement` بتنقص الرصيد؛ الحالة بتتحرك لوحدها حسب المتبقي.

### 2.5 الأرصدة الافتتاحية
```
مسودة ──── PostAccountOpeningBalanceBatch ───► مرحّلة
      ↘ CancelAccountOpeningBalanceBatch ──► ملغاة
```

### 2.6 المطابقة البنكية
```
قيد التنفيذ (InProgress) ──[AddBankReconciliationLine × n]──► CompleteBankReconciliation ──► مكتملة
```

### 2.7 الفترة المالية
```
مفتوحة (Open) ⇄ مقفولة (Closed)
   ClosePeriod / ReopenPeriod
```
**الإقفال بيفحص قائمة تدقيق** (`PeriodCloseChecklistItem`): كل القيود مرحّلة، كل السندات مرحّلة...
وأي محاولة ترحيل بتاريخ في فترة مقفلة **بتُرفض صراحة**.

## 3. محرك الترحيل — الوضع الحقيقي

`IPostingService` **مبني وشغّال**، وبيعمل:
- بناء القيد والتحقق من **التوازن**
- رفض الترحيل على **حساب تجميعي** (`IsPostable = false`)
- فرض **الأبعاد الإلزامية** المرتبطة بالحساب
- فحص **الفترة المالية المفتوحة**

### اللي **مش** مبني
`00-Posting-Engine-Architecture.md` بيوصف **محرك قوالب** كامل: `PostingTemplate`،
`PostingTemplateLine`، `PostingEvaluator`، `AmountFormulaType`، `ConditionType`، Registry للـResolvers،
و`JournalEntryTemplateSnapshot`.

**صفر من الكيانات دي موجودة.** يعني:
- `IPostingService` الحالي هو المحرك **البسيط** — المُنادي بيبني السطور بنفسه، وده مناسب للقيود
  اليدوية اللي المحاسب بيكتبها.
- المستندات الآلية (فاتورة بيع/شراء، فاتورة POS) **مش موصَّلة بيه** — لأن توصيلها بيتطلب القوالب.
